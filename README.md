# 💜 Recurrly — Subscription Manager

> **Track. Manage. Save.**

Recurrly is a mobile subscription management application designed to help users keep track of their recurring subscriptions, monitor expenses, and never miss important renewal dates.

With subscriptions for streaming, music, cloud storage, productivity tools, learning platforms, and more becoming increasingly common, it can be difficult to keep track of how much you're spending every month.

**Recurrly brings everything into one place.** 📱

---

## ✨ Features

- 📋 **Subscription Management**
  - Add and manage recurring subscriptions
  - Store subscription name, price, category, and renewal date
  - Keep all subscriptions organized in one place

- 💰 **Expense Tracking**
  - Track monthly recurring expenses
  - Understand how much you're spending on subscriptions
  - Get a clearer picture of your recurring costs

- 📅 **Renewal Tracking**
  - Keep track of upcoming renewal dates
  - Easily see which subscriptions are renewing soon

- 🔔 **Smart Reminders**
  - Get reminders before subscription renewals
  - Avoid unexpected recurring charges

- 📊 **Spending Statistics**
  - Analyze subscription spending
  - Understand spending patterns
  - Identify subscriptions that may no longer be necessary

- 🔐 **Authentication**
  - Secure user authentication
  - User account management powered by Clerk

- 📈 **Product Analytics**
  - Understand how users interact with the application
  - Product analytics powered by PostHog

- 🎨 **Modern Mobile UI**
  - Clean and responsive interface
  - Designed with a simple and user-friendly experience in mind
